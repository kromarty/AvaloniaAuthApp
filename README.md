# Avalonia Auth App

Небольшое десктоп-приложение на Avalonia для авторизации, регистрации и выхода через HTTP API.

## Используемые NuGet-пакеты

|---|---:|---|
| `Avalonia` | 12.1.4 | Основная библиотека для разработки кросс-платформенного пользовательского интерфейса Avalonia. Нужна для типов, привязок данных и XAML-приложения. |

## Внедрение зависимостей

Контейнер создаётся в `App.axaml.cs` через `ServiceCollection`. В нём зарегистрированы:

- `HttpClient` - общий HTTP-клиент с базовым адресом API;
- `AuthSession` - состояние текущей авторизованной сессии;
- `IAuthService` / `AuthService` - операции входа, регистрации, получения пользователя и выхода;
- `IRegistrationDialogService` / `RegistrationDialogService` - сервис открытия окна регистрации;
- `AuthViewModel`, `MainViewModel`, `View1ViewModel` и `View2ViewModel` - ViewModel для экранов приложения.

Регистрация через интерфейсы позволяет заменять HTTP-реализацию без изменения ViewModel. Жизненный цикл сервисов и ViewModel задаётся контейнером:

- `Singleton` - для сервисов и общих ViewModel с состоянием;
- `Transient` - для `View2ViewModel`, экземпляр которого создаётся при каждом запросе.

Контейнер создаётся один раз при запуске и освобождается вместе с desktop-приложением.

## Организация интерфейса

Интерфейс построен на XAML и следует паттерну MVVM:

- `Views` содержит окна и пользовательские элементы управления;
- `ViewModels` содержит состояние и команды для представлений;
- `Services` содержит сетевую и прикладную логику;
- `Models` содержит данные запросов и ответов API.

Оформление намеренно минимальное: Fluent-тема, отступы, интервалы, сетки и простые панели обеспечивают понятную компоновку без сложных визуальных эффектов.

Важные XAML-файлы:

- `Views/MainWindow.axaml` - основное окно и навигационная структура;
- `Views/AuthView.axaml` - вход, регистрация и состояние авторизации;
- `Views/RegisterWindow.axaml` - форма регистрации;
- `App.axaml` - тема и общий шаблон представлений.
